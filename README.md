# 혼터디 (Hontudy)

> 🚧 개발 진행 중 — 데모 GIF/스크린샷은 MVP 완성 후 추가 예정

AI와의 멀티턴 대화로 자신의 IT 지식 수준을 진단하고, 개인화된 문제를 풀며 성장하는 학습 앱입니다.

## 왜 만들었나

- 학원을 다니면서 등 하원길 지하철, 버스에서 뜨는 자투리 시간이 은근히 많았는데, 책이나 노트북을 펴기엔 애매하고 그냥 흘려보내기엔 아까웠습니다.
  손에 스마트폰 하나만 있어도 방금 배운 개념을 바로 문제로 확인해볼 수 있으면 좋겠다는 생각에서 시작했고,
  매번 비슷한 난이도의 문제만 반복하기보다는 지금 내 수준에 맞는 문제를 AI가 진단해서 던져주는 방식으로 설계하게 되었습니다.

## 핵심 기능 (MVP 1단계)

- [ ] 로그인 (Firebase Auth)
- [ ] AI 진단 — 멀티턴 대화로 배경/난이도/목적 태그 파악
- [ ] 문제 풀이 — 진단 결과 기반 개인화 문제 출제 및 채점
- [ ] 노트 — 풀이 기록 모아보기
- [ ] 마이페이지

> 2단계(대시보드, 랭킹, 카테고리 확장 등)는 1단계 완성 후 착수합니다.

## 기술 스택

| 분류 | 선택                                              | 이유                                                               |
| --- |-------------------------------------------------|------------------------------------------------------------------|
| 아키텍처 | MVVM + Clean Architecture                       | presentation/domain/data 물리적 분리로 관심사 강제 분리                       |
| 상태관리/DI | Riverpod (`AsyncNotifier`)                      | provider 그래프 자체가 DI 컨테이너 역할, 컴파일타임 안전성                           |
| 에러 처리 | `result_dart`                                   | 예외 대신 `Success`/`Failure`로 성공/실패를 타입으로 명시                        |
| 네트워크 | `dio`                                           | ChatGPT REST 직접 호출 — 구조화된 출력 등 최신 기능을 세밀한 파라미터 제어로 안정적으로 사용하기 위함 |
| 불변 모델 | `freezed` + `json_serializable`                 | 도메인 모델/LLM 응답 파싱을 불변 객체로 안전하게                                    |
| 동적 UI | `package:genui`                                 | LLM 응답에 따라 위젯을 동적으로 렌더링 (GenUI)                                  |
| 인증/DB | Firebase Auth + Firestore                       | 인증 및 진단/풀이 이력 영속 저장                                              |
| LLM | ChatGPT                                           |

## 아키텍처

```
lib/
├── presentation/   # View, ViewModel (AsyncNotifier)
├── domain/         # UseCase, Repository 인터페이스, 도메인 모델
└── data/           # Repository 구현체, Service(외부 시스템 wrapper), Dto
```

View → ViewModel → UseCase → Repository로 이벤트가 내려가고, 상태는 반대 방향으로만 흐르는 단방향 데이터 흐름(UDF)을 따릅니다.
자세한 설계 근거는 추후 별도 문서로 정리 예정입니다.
